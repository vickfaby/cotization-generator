## /hoy (Cursor)

Objetivo: retomar el contexto en 1–2 minutos y proponer una acción concreta.

Instrucciones:
- Lee/usa como fuente de verdad:
  - `docs/prd.md` (objetivo)
  - `docs/roadmap.md` (estado)
  - `docs/decisions-log.md` (últimas ADRs)
  - `docs/testing-strategy.md` (tests)
- Identifica:
  - ticket “siguiente” (o propone uno nuevo si falta)
  - riesgos o drift evidente
  - estado de tests (si hay comando, ejecútalo)

Entrega un briefing corto con:
- Proyecto (1 línea)
- Objetivo (1 línea)
- Progreso (qué está en “Hecho” vs “Backlog”)
- Último cerrado / siguiente
- Tests (verde/rojo + comando)
- Últimas decisiones (2–3 ADRs o “ninguna”)
- Warnings (drift / deuda)
- Sugerencia concreta para hoy (una)
