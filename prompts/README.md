# Prompts (KUIPAD scaffolding)

Estos prompts reemplazan los slash commands de Windsurf para usarlos en Cursor.

## Cómo usarlos

1. Abre el prompt que necesites en `prompts/workflows/`.
2. Copia y pégalo en el chat de Cursor.
3. Responde a las preguntas y deja que el agente ejecute el protocolo.
